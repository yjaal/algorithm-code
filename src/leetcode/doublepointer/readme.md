双指针法是利用数据的有序性（数组）或空间特性（链表/字符串）来缩减算法复杂度的技巧。

*   **核心场景**：在数组、链表、字符串中寻找特定条件的元素对、子数组或子序列。
*   **解题套路**：
    1.  **左右指针 (相向/背向)**：主要应用于**有序数组**。例如，寻找和为target的两个数，若当前两数和大于target，则右指针左移，反之左指针右移。反转数组、验证回文串也属于此类。
    2.  **快慢指针 (同向)**：
        *   **数组**：用于原地移除元素、去重等操作。快指针用于遍历数组，慢指针指向待填充的位置。
        *   **链表**：详见链表部分。
    3.  **滑动窗口 (同向双指针)**：专门处理**连续子数组/子串**问题。右指针负责扩展窗口，左指针负责收缩窗口，在窗口移动过程中记录答案。是求“和>=target的最小子数组”、“无重复最长子串”等问题的标准解法。

    *   [26. 删除有序数组中的重复项](https://leetcode.cn/problems/remove-duplicates-from-sorted-array/) (快慢指针)
    *   [209. 长度最小的子数组](https://leetcode.cn/problems/minimum-size-subarray-sum/) (滑动窗口入门题)
    *   [11. 盛最多水的容器](https://leetcode.cn/problems/container-with-most-water/) (左右指针，面试高频)
