单调栈是一种特殊的数据结构，它栈内元素始终保持单调递增或递减。它专门用于解决寻找数组中某元素左边或右边“第一个”比它大或比它小的元素问题。

*   **核心场景**：下一个更大/更小元素（Next Greater Element）、接雨水、柱状图最大矩形。
*   **解题套路**：
    1.  **维护单调性**：
        *   寻找**下一个更大元素**：维护一个**单调递减栈**（栈底到栈顶递减）。遍历数组，当当前元素大于栈顶元素时，栈顶元素出栈，当前元素就是其“下一个更大元素”。
        *   寻找**下一个更小元素**：维护一个**单调递增栈**。
    2.  **循环数组**：处理循环数组问题时，可以通过将数组长度翻倍（遍历`2*n`次，索引取模）来模拟循环查找。
    3.  **经典应用**：“接雨水”问题需要维护一个递减栈，当遇到高度大于栈顶的元素时，形成凹槽，可以计算雨水量。

    *   [84. 柱状图中最大的矩形](https://leetcode.cn/problems/largest-rectangle-in-histogram/) (单调栈经典题)
