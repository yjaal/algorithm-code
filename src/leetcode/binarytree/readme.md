二叉树的题目几乎都与递归或迭代（借助栈/队列）相关，需要深刻理解树的遍历顺序。

*   **核心场景**：各种遍历（前、中、后、层）、计算深度/直径、路径和、最近公共祖先、判断对称性/平衡性、构造二叉树。
*   **解题套路**：
    1.  **递归三要素**：几乎所有递归解法都遵循这个模板：确定递归函数的参数和返回值、确定终止条件（通常是节点为`null`）、确定单层递归的逻辑（决定何时调用左/右子节点）。
    2.  **遍历与迭代**：熟练掌握递归的三种顺序（前、中、后序）。对于迭代法，前/后序相对简单，中序遍历则较复杂，需借助栈。**层序遍历**（BFS）必须会用队列实现，这是解决“二叉树的右视图”、“按层输出”等问题的基础。
    3.  **二叉搜索树 (BST)**：牢记其中序遍历结果是**有序数组**。利用这个性质，可以高效地查找第K小元素、验证是否为BST。
