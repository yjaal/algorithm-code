回溯的本质是N叉树的深度优先搜索（DFS），它试图在问题的所有解空间中找到满足条件的解。

*   **核心场景**：组合问题、排列问题、子集问题、切割问题（如分割回文串）、棋盘问题（如N皇后、解数独）。
*   **解题套路**：
    1.  **回溯三部曲**：这是一个通用框架：
        1.  确定递归函数的参数和返回值（通常包括`路径`和`选择列表`）。
        2.  确定终止条件（通常是到达叶子节点，即`路径`满足要求）。
        3.  处理单层搜索逻辑（遍历`选择列表`，做选择，递归，撤销选择）。
    2.  **去重（剪枝）**：这是回溯算法中最关键、最难的环节。当数组中包含重复元素时，为了避免产生重复结果，需要先对数组进行排序，然后在同一层搜索中跳过重复的元素。
    3.  **复杂度**：回溯算法的时间复杂度通常是指数级的，因此**剪枝**是优化代码性能的核心手段。
