贪心算法的核心是：在对问题求解时，总是做出在当前看来是最好的选择，以期望得到全局最优解。它的难点在于证明“局部最优”能推导出“全局最优”。

*   **核心场景**：区间调度、分配问题（如分发饼干）、股票买卖（如多次交易）、覆盖问题（如跳跃游戏）。
*   **解题套路**：
    1.  **排序与优先处理**：很多贪心问题的第一步都是对数据进行排序，然后按顺序处理。例如，在区间合并问题中，按区间的起始位置排序；在活动选择问题中，按活动的结束时间排序。
    2.  **从极端情况入手**：考虑问题的最左端或最右端应该如何处理，往往能发现贪心策略。例如，在“加油站”问题中，考虑总油量和总耗油量的关系。
    3.  **无后效性**：贪心选择的结果不会对未来的决策产生负面影响（或影响是可控的）。如果当前的选择会影响未来状态，则贪心算法可能不适用，应考虑动态规划。
