
# 数组常见套路

## 1. 双指针（快慢指针 & 左右碰撞指针）

### 快慢指针：通常用于原地删除/去重/移动元素。

场景：给你一个数组，要求删除某个元素，或移除所有0，且不能开新数组。

思路：slow指针指向待插入位置，fast指针遍历数组。当fast指向有效元素时，将其赋值给slow，slow后移。

经典题：LeetCode 27（移除元素）、26（删除有序数组重复项）、283（移动零）。

### 左右碰撞指针：通常用于有序数组的搜索或反转。

场景：数组有序，需要找两个数使它们之和等于目标值，或进行数组反转。

思路：left指向头，right指向尾。根据两数之和与目标值的大小关系，决定是移动left还是right。

经典题：LeetCode 167（两数之和 II）、344（反转字符串）。

## 2.前缀和（含前缀积）
当你看到题目问“连续子数组的和/积”、“区间和”时，首选前缀和。它能把区间和问题转化为两个前缀和相减的问题。

场景：频繁查询数组中任意一段区间 `[i, j]` 的元素和。

思路：预处理一个数组 `pre`，其中 `pre[i]` 表示 `nums[0]` 到 `nums[i-1]` 的和。那么区间和 `sum(i, j) = pre[j+1] - pre[i]`。

进阶（哈希表优化）：如果题目问的是和为K的子数组个数，单纯前缀和是 `O(n²)`。此时需要用 HashMap 记录前缀和出现的次数，遍历时查找 当前前缀和 - K 是否出现过。

经典题：LeetCode 560（和为K的子数组）、238（除自身以外数组的乘积——这是前缀积）。

这里一般可以使用暴力解法，但是更好的是使用前缀和解法。

前缀和：
预处理一个前缀数组
pre[i] 表示 nums[0] 到 nums[i-1] 的和。
比如 `nums = [1,2,6,4,-1,5]`，那么 `pre = [0, 1, 3, 9, 13, 12, 17]`，于是
`sum(i, j) = pre[j+1] - pre[i]`，这里从 `i` 到 `j` 就是一个连续子串。
于是找和为K的子串的个数:
```java
int count = 0;
for (int i = 0; i < nums.length; ++i) {
    for (int j = i; j < nums.length; ++j) {
    //注意偏移，因为我们的nums[2]到nums[4]等于presum[5]-presum[2]
    //所以这样就可以得到nums[i,j]区间内的和
    if (presum[j+1] - presum[i] == k) {
        count++;
        }
    }
}
```
但是这里的时间复杂度是`O(n^2)`，于是可以使用哈希表优化为`O(n)`。哈希表其实就是找两数之和
的方法，就是将前缀和作为哈希表的 Key，出现的次数作为 Value。
```java
public int subarraySum(int[] nums, int k) {
    if (nums.length == 0) {
        return 0;
    }
    HashMap<Integer,Integer> map = new HashMap<>();
    //细节，这里需要预存前缀和为 0 的情况，会漏掉前几位就满足的情况
    //例如输入[1,1,0]，k = 2 如果没有这行代码，则会返回0,漏掉了1+1=2，和1+1+0=2的情况
    //输入：[3,1,1,0] k = 2 时则不会漏掉
    //因为presum[3] - presum[0]表示前面 3 位的和，所以需要map.put(0,1),垫下底
    map.put(0, 1);
    int count = 0;
    int presum = 0;
    for (int x : nums) {
        presum += x;
        // 当前前缀和已知，判断是否含有 presum - k的前缀和，那么我们就知道某一区间的和为 k 了。
        if (map.containsKey(presum - k)) {
            count += map.get(presum - k);//获取presum-k前缀和出现次数
        }
        //更新
        map.put(presum,map.getOrDefault(presum,0) + 1);
    }
    return count;
}

```
其实这里相当于map中存储前缀和与其出现的次数，关键理解点就在于我们每次去找 `presum - k`，其实就
相当于找一个 `i, j`之间的子串和是否等于 k。那这里就可以扩展了，有了前缀就会
有后缀。比如后缀和与后缀积。


## 3.滑动窗口（双指针的变形）
这是双指针的进阶用法，专门解决子数组/子串的最值问题（最长、最短、覆盖）。

场景：求满足某个条件（如和 >= target，或不含重复字符）的连续子数组的最小长度或最大长度。

思路：右指针向右扩展窗口，左指针根据条件向右收缩窗口，期间不断更新答案。

关键点：核心在于窗口内数据的维护，通常配合 HashMap 或数组计数。

经典题：LeetCode 209（长度最小的子数组）、3（无重复字符的最长子串）。

这里要注意，ASCII字符最大127，可以使用`int[128]`存储。

## 4.模拟（找规律/螺旋矩阵）
这类题不考复杂算法，纯粹考代码控制力和边界处理。

场景：矩阵旋转、螺旋遍历、Z字形打印等。

思路：设定好四个边界（上、下、左、右），按照方向顺序（如：左→右，上→下，右→左，下→上）循环遍历，每走完一条边就收缩对应的边界。

经典题：LeetCode 54（螺旋矩阵）、59（螺旋矩阵 II）、48（旋转图像）。

## 5.原地哈希（鸽巢原理/负数标记）
这是数组题中一个非常“骚”的技巧，用于 O(1) 空间 且 O(n) 时间 内找到缺失的正数或重复元素。

场景：数组长度 n，元素大小在 1~n 之间，要求找缺失的第一个正数，或找重复数。

思路：利用数组下标作为哈希表的 Key。通过交换，将数字 `nums[i]` 放到
下标 `nums[i]-1` 的位置上（即 `nums[i] == i+1`）。遍历结束后(得到的数组并不一定就是排好序的)，
再次便利，第一个下标与数字不匹配的位置即为答案（注意，遍历时 i 要大于0）。

或者（负数标记法）：遍历数组，将 `nums[abs(nums[i])-1]` 标记为负数，表示该数字已出现过。这个方法
有点绕。

经典题：LeetCode 41（缺失的第一个正数）、442（数组中重复的数据）。


# 一般经验总结

## 计算中间位置

错误写法
```java
// 存在溢出风险
int mid = (left + right) / 2;
```

一般安全写法
```java
int mid = left + (right - left) / 2;
```

推荐写法
```java
// 无溢出风险
int mid = (left + right) >>> 1;
```
