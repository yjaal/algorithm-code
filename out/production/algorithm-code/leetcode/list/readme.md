
链表题的核心难点在于“指针的安全操作”。

## 一、 虚拟头节点（Dummy Node）套路
核心思想：在链表的最前面人为添加一个不存储真实数据的假节点。它的主要作用是统一处理边界情况，避免在删除或反转头节点时进行繁琐的特判。只要头节点可能发生变化，就优先考虑使用 Dummy 节点。
- LeetCode 203：移除链表元素（统一处理头节点被删除的情况）就是先定义一个前置节点，使用一个临时节点dummy进行处理，最后返回pre.next
- LeetCode 21：合并两个有序链表（统一处理结果链表的构造，避免空链表判断）
- LeetCode 86：分隔链表（维护两个 Dummy 头节点，分别挂载小于和大于目标值的节点）

## 二、 快慢指针（Two Pointers）套路
核心思想：利用两个指针同向移动但速度不同（通常 fast 走 2 步，slow 走 1 步），在链表中构造“速度差”和“距离差”。由于链表不能随机访问，这种技巧是解决位置问题和环问题的利器。
- LeetCode 141：环形链表（快指针追上慢指针即有环）
- LeetCode 142：环形链表 II（相遇后，快指针回起点同速前进，再次相遇即为入环点）
- LeetCode 876：链表的中间结点（fast 到末尾时，slow 刚好在中点）
- LeetCode 19：删除链表的倒数第 N 个结点（fast 先走 n 步，然后同步走，fast 到末尾时 slow 即为待删节点前驱）

## 三、 指针反转与重连套路
核心思想：修改节点之间的 next 方向。这类操作的硬规则是：在修改 cur.next 之前，必须先保存 nxt = cur.next，防止链表断裂丢失后续节点。
- LeetCode 206：反转链表（最基础的反转模板：pre / cur / next 滚动更新）
- LeetCode 92：反转链表 II（反转链表的局部区间）
- LeetCode 24：两两交换链表中的节点（成对进行指针重连，重点在维持反转链表的前序链表和头节点）
- LeetCode 25：K 个一组翻转链表（结合 Dummy 节点与局部反转，注意不足 k 个时保持原序，略难）
- LeetCode 234：回文链表（组合拳：快慢指针找中点 + 反转后半部分 + 逐一比较）

## 四、 链表合并与深拷贝套路
核心思想：
合并：通常使用 dummy + tail 模板，每次选取符合条件的节点接到 tail 后面，并移动 tail。
深拷贝：处理带有额外指针（如 random）的复杂结构，需要建立新旧节点的映射关系。
- LeetCode 21：合并两个有序链表（基础双链表合并）
- LeetCode 23：合并 K 个升序链表（借助最小堆或分治思想进行多路合并,分治+合并）
- LeetCode 138：复制带随机指针的链表（利用哈希表映射或原地穿插法处理随机指针）
