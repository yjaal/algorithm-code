动态规划是面试中的绝对重点和难点，其核心是“用子问题的解来推导原问题的解”，关键是定义好状态（`dp`数组）和状态转移方程。

*   **核心场景**：求解最值（最大/最小）、方案数、可行性问题，以及经典的背包问题、最长公共子序列(LCS)、最长递增子序列(LIS)、编辑距离等。
*   **解题套路（动规五部曲）**：
    1.  **确定dp数组含义**：`dp[i]` 或 `dp[i][j]` 代表什么状态？这是最重要的一步。
    2.  **确定递推公式**：`dp[i]` 如何由之前的状态推导出来？例如，爬楼梯问题 `dp[i] = dp[i-1] + dp[i-2]`。
    3.  **确定dp数组如何初始化**：根据递推公式，找出最基础的几个状态并正确赋值。
    4.  **确定遍历顺序**：这是解决动态规划题目的关键，尤其是在背包问题中。需要明确是从前往后还是从后往前，以及是遍历物品还是遍历背包容量。
    5.  **举例推导dp数组**：在纸上或脑中模拟小规模输入，验证dp数组的变化是否符合预期，可以有效地发现逻辑错误。
*   **进阶技巧**：**状态压缩**，当`dp[i]`只依赖`dp[i-1]`时，可以用滚动数组将二维DP降至一维，从而优化空间复杂度。
